In this challenge, we will enable access to the http port 80 on
`*rhelvm*`.

First, we’ll prove to ourselves that port 80 is blocked by the firewall
running on `*rhelvm*`.

Switch to the `*rhelvm*` terminal by clicking
on this button:

.rhelvm tab
image::rhelvm-tab.png[rhelvm tab]

Run the following in in the `*rhelvm*` tab:

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
firewall-cmd --list-all
----

.Output
[source,text]
----
public (active)
  target: default
  icmp-block-inversion: no
  interfaces: eth0
  sources:
  services: cockpit dhcpv6-client ssh
  ports:
  protocols:
  forward: yes
  masquerade: no
  forward-ports:
  source-ports:
  icmp-blocks:
  rich rules:
----

The output above shows that port 80 is not open.

In the `*rhelvm*` terminal, run `*nc -l 80*`. This command runs the utility
`*netcat*` and tells it to listen for incoming traffic on port 80.

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
nc -l 80
----

.Output
[source,text]
----
nc -l 80

----

`*netcat*` is now listening on port 80 on `*rhelvm*`.

IMPORTANT: The `*nc*` command continues listening until cancled. Do not exit out of `*nc*` in this terminal until instructed to do so.

Switch back to the `*>_ controlnode*' terminal.

Enter the command `*nc rhelvm 80*`. This tells `netcat` to connect to port
80 on `*rhelvm*`.

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
nc rhelvm 80
----

.Output (Failure expected)
[source,text,subs="+macros,+attributes"]
----
[root@controlnode ~]# nc rhelvm.{{ guid }}.internal 80
Ncat: No route to host.
----

`*netcat*` cannot connect to `*rhelvm*` on port 80.

Use the recently installed RHEL systems roles to open up port 80 on `*rhelvm*`.

First, Ansible requires a host file pointing at the `*rhelvm*` host. The
host file looks like this.

Copy and paste the following into the `*>_ controlnode*' terminal.

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
tee -a /root/hosts << EOF
all:
  hosts:
    rhelvm.{{ guid }}.internal:
  vars:
    firewall:
      - service: http
        state: enabled
EOF
----

Next, we’ll create a simple Ansible playbook that tells ansible to apply
the RHEL Firewall system role.

Copy paste and run the following in the CLI.

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
tee -a /root/firewall.yml <<EOF
- name: Configure Firewall
  hosts: all
  roles:
    - redhat.rhel_system_roles.firewall
EOF
----

Now we’ll apply the system role to `*rhelvm*` by running the following
command on `*>_ controlnode*'

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
ansible-playbook -i hosts -b firewall.yml
----

.Output
[source,text,subs="+macros,+attributes"]
----
<<< OUTPUT ABRIDGED >>>

TASK [redhat.rhel_system_roles.firewall : Configure firewall] ************************************************************
changed: [rhelvm.{{ guid }}.internal] => (item={'service': 'http', 'state': 'enabled'})

<<< OUTPUT ABRIDGED >>>

PLAY RECAP *************************************************
rhelvm.{{ guid }}.internal      : ok=9    changed=1    unreachable=0    failed=0    skipped=12   rescued=0    ignored=0
----

Run `*nc rhelvm 80*` in the `*>_ controlnode*' terminal again.

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
nc rhelvm 80
----

IMPORTANT: Once the command is executed the terminal will await further input. This allows us to test connectivity.

Enter text into the terminal and press the enter key.

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
the quick brown fox jumps over the lazy dogs
----

Exit out of `*nc*` command after entering the text on the `*>_ controlnode*` terminal by typing `*ctrl-c*`. This will cause `*nc*` to exit in the `*rhelvm*` tab.

Finally, we’ll use `*firewall-cmd*` to list the open ports on
`*>_ rhelvm*`.

Switch to the `*>_ rhelvm*` terminal.

NOTE: You will see the quote you entered quote on this terminal as well.

Run the following command to list the active firewall rules.

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
firewall-cmd --list-all
----

.Output
[source,text]
----
public (active)
  target: default
  icmp-block-inversion: no
  interfaces: eth0
  sources:
  services: cockpit dhcpv6-client http ssh
  ports:
  protocols:
  forward: yes
  masquerade: no
  forward-ports:
  source-ports:
  icmp-blocks:
  rich rules:
----

The `*http*` service was added to the firewall rules by ansible.
