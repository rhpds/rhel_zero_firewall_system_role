Next we will open port 9999 on `*rhelvm*`.

In the `*>_ controlnode*` terminal, add the lines
`*- port: ['9999/tcp']*` and `*state: enabled*` to the `*hosts*` file.

The following command will add those lines for you.

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
tee -a /root/hosts << EOF
      - port: ['9999/tcp']
        state: enabled
EOF
----

Now run the playbook in the `*>_ controlnode*`
terminal.

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
ansible-playbook -i hosts -b firewall.yml
----

[source,text,subs="+macros,+attributes"]
----

In the `*>_ rhelvm*` terminal, run `*nc*`, listening
on port 9999.

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
nc -l 9999
----

In the `*>_ controlnode*` terminal, run the `*nc*` command:

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
nc rhelvm 9999
----

Type words to test connectivity as you did before and press enter.

.Command
[source,bash,subs="+macros,+attributes",role=execute]
----
the quick brown fox jumps over the lazy dogs
----

In the `*>_ controlnode*` terminal, type `*ctrl-c*`
to exit `*nc*`.
